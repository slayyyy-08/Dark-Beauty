# Nocturne Beauty - Gothic Makeup Website

## 1. About the Project
Dark Beauty is a simple gothic-themed makeup website.
It uses black and crimson colours and displays makeup products.

## 2. Objective
The objective of this project is to learn basic web development
using HTML, CSS, and JavaScript.

## 3. Technologies Used
- HTML: Creates the structure of the website.
- CSS: Adds colours, styling, and design.
- JavaScript: Makes the Add to Cart button interactive.

## 4. Features
- Gothic black and crimson theme.
- Makeup product image.
- Product name and price.
- Add to Cart button.
- Simple and beginner-friendly design.

## 5. Project Structure
- index.html - Website structure.
- style.css - Website design.
- script.js - Button interaction.
- README.md - Project documentation.

## 6. How to Run
1. Download or clone the GitHub repository.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser.
4. Click the Add to Cart button.

## 7. Future Improvements
- Add more makeup products.
- Create a functional shopping cart.
- Add product categories.
- Create a checkout page.
- Improve mobile responsiveness.

## 8. Conclusion
This project helped me understand the basics of HTML,
CSS, and JavaScript and how they work together to create
a simple interactive website.
